# LESSONS — the agent's episodic memory

Before every task: read the 3 most recent entries and apply them.
After every attempt (pass or fail): append exactly one entry.
Keep entries short. This file is memory, not a diary.

Format (copy this):

```
## [date] — [task, 5 words max] — PASS|FAIL
- What happened: [one line]
- Root cause / why it worked: [one line]
- Next time: [one specific, checkable instruction]
```

Rules:
- "Next time" must be actionable ("run migrations before seeding") not vague ("be more careful").
- On PASS, record what made it work — success patterns are lessons too.
- When the file exceeds ~30 entries, compress the oldest 20 into a "Standing
  rules" list at the top and delete them. Recurring lessons graduate into
  standing rules; one-off details get dropped.
